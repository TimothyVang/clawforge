# Prompt — weekly status

1. Linear: completed this week, still open high-priority, at-risk projects.
2. GitHub: merged PRs, open PRs, failed CI (if any).
3. Post to Discord **#general** or **#standup**:

```
**Week of {date}**
Shipped: …
In flight: …
Risks: …
Next: …
```

Keep under 15 lines. Use TEAM-n IDs only.
